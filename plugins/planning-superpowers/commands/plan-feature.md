name: plan-feature
description: Kick off the deep-planning workflow for a big/ambiguous task — brainstorm the requirements, design a phased plan, then commit it.
---
Run the deep-planning workflow for the current goal:

1. Inspect the workspace freely to ground yourself (no plan needed yet).
2. If the goal is ambiguous, delegate a `brainstormer` to sharpen requirements and pick an approach; `record_decision` for the chosen direction.
3. Delegate an `architect` to return a structured PLAN PROPOSAL grounded in the workspace.
4. Turn the proposal into `plan_create` (mission, success_criteria, constraints, phases, first-phase steps), tagging self-contained steps with `delegate=<agent>`.
5. Execute one phase at a time, verifying each change and advancing phases at milestones.

Load the `deep-planning` skill for the full discipline.
